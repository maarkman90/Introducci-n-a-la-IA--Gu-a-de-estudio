Esta guía no te da respuestas masticadas. Te da conceptos clave, preguntas disparadoras y pistas de búsqueda para que tú construyas el conocimiento investigando, probando y conectando ideas por tu cuenta.

1

El Cambio de Paradigma

De programar reglas a entrenar con datos.

Concepto breve

Durante décadas la computación funcionó así: un humano escribe reglas explícitas (if-else) y la máquina las ejecuta. La IA moderna, especialmente el Machine Learning, invierte la lógica: le damos muchos ejemplos (datos) y el sistema infiere sus propias reglas (un modelo estadístico) para generalizar a casos nuevos.

2

Anatomía de un LLM

Qué hay realmente detrás de un chat como ChatGPT, Gemini o Claude.

Concepto breve

Un Large Language Model (LLM) es una red neuronal entrenada con cantidades masivas de texto para predecir la siguiente palabra (o "token") más probable dada una secuencia previa. No "entiende" ni "piensa" como un humano: calcula probabilidades a partir de patrones estadísticos aprendidos del lenguaje.

🔡

Token

Clic para revelar

Unidad mínima de texto que procesa un modelo: puede ser una palabra, parte de una palabra o un signo. Investiga cómo un tokenizador divide "inteligencia artificial".

Clic para revelar

3

Interfaz vs. Modelo

No confundas la "app" con el "cerebro".

Concepto breve

ChatGPT, Copilot y Gemini son interfaces: aplicaciones con una capa de producto (memoria, herramientas, moderación, UI) construidas sobre un modelo base (GPT-4o, Gemini, Claude). El mismo modelo puede exponerse en múltiples interfaces distintas, cada una con reglas y capacidades diferentes.

Capa Qué es Ejemplo
Modelo El motor estadístico entrenado GPT-4o, Gemini 1.5, Claude 3
API Puerta de acceso programática al modelo OpenAI API, Vertex AI
Interfaz / App UI + memoria + herramientas + reglas de uso ChatGPT, Copilot, Gemini App

Asistentes Personalizados (GPTs)

Configurar un modelo sin entrenarlo de nuevo.

Concepto breve

Un "GPT personalizado" o asistente a medida no entrena un nuevo modelo desde cero. En realidad envuelve el modelo base con instrucciones persistentes (un prompt de sistema detallado), conocimiento adicional (archivos de referencia) y a veces herramientas (búsqueda, código, APIs externas). Es personalización por configuración, no por reentrenamiento.

5

Límites y Fronteras del Prompt

Lo que un prompt puede y no puede lograr.

Concepto breve

Un prompt bien diseñado puede guiar el tono, formato, rol y enfoque de un modelo, pero no puede otorgarle conocimiento que no estaba en sus datos de entrenamiento, ni eliminar sus sesgos estructurales, ni garantizar exactitud factual al 100%. Entender estas fronteras evita expectativas irreales y usos riesgosos.
